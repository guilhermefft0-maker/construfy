2. Descrição do Serviço

O ConstruPRO é uma plataforma SaaS (Software as a Service) de gestão de obras, voltada a engenheiros, construtoras e profissionais da construção civil. Entre as funcionalidades oferecidas, destacam-se:

  • Cadastro e gestão de obras
  • Controle de medições e faturamento
  • Controle de ponto de colaboradores
  • Diário de obra e relatórios
  • Cotação e controle de compras
  • Folha de pagamento e EPIs
  • Controle financeiro e exportação de dados

As funcionalidades disponíveis variam conforme o plano contratado pelo Usuário (Free ou PRO), conforme descrito na Seção 4.

9.1 Dados fornecidos diretamente pelo Usuário

  • Dados de cadastro: nome, e-mail e senha — para criação e autenticação da conta;
  • Dados de obras e projetos: informações inseridas pelo Usuário sobre suas obras, medições, faturamentos e colaboradores — para prestação do serviço contratado;

9.2 Dados coletados automaticamente

  • Dados de uso: páginas acessadas, funcionalidades utilizadas, data e hora de acesso — para melhoria da Plataforma;
  • Dados técnicos: endereço IP, tipo de dispositivo e navegador — para segurança e diagnóstico técnico.

9.3 Base legal para o tratamento

Os dados pessoais são tratados com base nas seguintes hipóteses legais previstas na LGPD:

  • Execução de contrato (art. 7º, V): dados necessários para prestação do serviço;

  • Cumprimento de obrigação legal (art. 7º, II): quando exigido por lei ou autoridade competente.

9.4 Compartilhamento de dados

O ConstruPRO não vende dados pessoais a terceiros. Os dados poderão ser compartilhados apenas com:

  • Kiwify: para processamento de pagamentos;
  • Cloudflare: para hospedagem e segurança da infraestrutura;
  • Vercel: para hospedagem do frontend da Plataforma;

9.5 Retenção dos dados

Os dados pessoais são mantidos pelo período necessário à prestação do serviço e, após o encerramento da conta, pelo prazo mínimo exigido pela legislação aplicável (em geral, 5 anos para dados fiscais e 1 ano para logs de acesso, conforme o Marco Civil da Internet).
